# -Natura-2000-QGIS
Χρησιμοποιώντας το πρόγραμμα QGIS σε συνδυασμό με ελεύθερα δεδομένα δημιούργησα ένα πρότζεκτ στο οποίο διαχωρίζονται οι περιοχές Natura 2000. 
Αυτή η οριοθέτηση είναι πολύ σημαντική και πρέπει να λαμβάνεται υπόψιν πριν την εκτέλεση οποιουδήποτε έργου, είτε είναι φωτοβολταϊκό πάρκο, είτε ο σχεδιασμός οδικού δικτύου ή οποιαδήποτε άλλη δραστηριότητα.
Οι περιοχές Natura 2000 είναι ένα ευρωπαϊκό δίκτυο προστατευόμενων φυσικών ζωνών που δημιουργήθηκε για τη διασφάλιση της επιβίωσης των πιο πολύτιμων και απειλούμενων ειδών και οικοτόπων της Ευρώπης, προωθώντας παράλληλα την αρμονική συνύπαρξη της φύσης με την ανθρώπινη δραστηριότητα.
